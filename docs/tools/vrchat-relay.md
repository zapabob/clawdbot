# VRChat Relay

The `vrchat-relay` plugin provides comprehensive VRChat integration using the OSC protocol. It enables the agent to control avatars, send chatbox messages, manage camera settings, run autonomous presence heartbeats, and drive an OpenClaw-ready own avatar through structured AI decisions.

Own-avatar control uses the official VRChat OSC avatar-parameter API. It only
drives the avatar you are already wearing in the official VRChat client, and it
does not handle VRChat credentials, modify the client, or load FBX files at
runtime.

For existing published avatars that you do not want to edit in Unity, use the
Hypura Harness existing-avatar flow. It reads the OSC JSON generated by VRChat,
builds a candidate per-avatar action profile, and writes to VRChat only after
the user approves that profile.

Autonomous VRChat AI Avatar adds an InputHub for text, STT, vision observations,
and stream comments; a structured `AgentDecision` request builder that defaults
to `gpt-5.5` with low reasoning; VOICEVOX request generation; audio speaking
events; and opt-in ChatBox output. It still uses only official VRChat OSC.

## Permission Levels

Tools are gated behind three permission levels (default: `SAFE`):

| Level      | Description                                                           |
| ---------- | --------------------------------------------------------------------- |
| `SAFE`     | Chatbox messaging, avatar params, OSC listener, friends/world info    |
| `PRO`      | Input commands (Jump, Move, Look, Voice) when `movement.enabled=true` |
| `DIRECTOR` | Camera control (Zoom, Aperture, GreenScreen, LookAtMe, Capture)       |

Use `vrchat_permission_set` to escalate. `vrchat_login` is only for optional
VRChat Web API tools such as friends and world info; own-avatar OSC control
uses the official client session that you logged into yourself.

## Authentication

```
vrchat_login({ username, password, totpSecret? })
vrchat_status()
vrchat_logout()
```

## Tools Reference

### Chatbox & Presence

| Tool             | Description                                             |
| ---------------- | ------------------------------------------------------- |
| `vrchat_chatbox` | Send message to VRChat chatbox (max 144 chars, 9 lines) |
| `vrchat_typing`  | Set typing indicator on/off                             |

### Avatar Control

| Tool                      | Description                             |
| ------------------------- | --------------------------------------- |
| `vrchat_set_avatar_param` | Set avatar parameter (bool/int/float)   |
| `vrchat_discover`         | Discover avatar parameters via OSCQuery |
| `vrchat_change_avatar`    | Change avatar via OSC                   |

### Own avatar controller

| Tool                               | Description                                                          |
| ---------------------------------- | -------------------------------------------------------------------- |
| `vrchat_own_avatar_status`         | Show current avatar readiness and safety state                       |
| `vrchat_own_avatar_enable`         | Enable or disable autonomous own-avatar OSC control                  |
| `vrchat_own_avatar_set_state`      | Send a state, optional emotion, and optional action id               |
| `vrchat_own_avatar_test_command`   | Run smoke commands such as `happy`, `think`, `wave`, `reset`         |
| `vrchat_own_avatar_look`           | Send clamped local look values when the avatar profile supports them |
| `vrchat_own_avatar_emergency_stop` | Stop autonomy and return the avatar to neutral parameters            |

For existing published avatars, start with the Hypura tools:

1. Log in with the official VRChat client.
2. Enable OSC from the VRChat Action Menu.
3. Wear the avatar once so VRChat generates
   `OSC/<userId>/Avatars/<avatarId>.json`.
4. Run `hypura_harness_vrc_status`, `hypura_harness_vrc_parameters`, and
   `hypura_harness_vrc_suggest_profile`.
5. Review and approve the generated profile only after confirming each mapped
   action.
6. Use `hypura_harness_vrc_action` for expression or gesture writes.

### Autonomous VRChat AI Avatar

| Tool                                      | Description                                                                   |
| ----------------------------------------- | ----------------------------------------------------------------------------- |
| `vrchat_ai_avatar_status`                 | Show InputHub, orchestrator, VOICEVOX, audio, ChatBox, STT, and safety status |
| `vrchat_ai_avatar_ingest`                 | Add `textBox`, `speechToText`, `visionObservation`, or `streamComment` input  |
| `vrchat_ai_avatar_build_decision_request` | Build the `gpt-5.5` low-reasoning structured `AgentDecision` request          |
| `vrchat_ai_avatar_run_decision`           | Run runtime LLM orchestration from buffered inputs and apply the decision     |
| `vrchat_ai_avatar_apply_decision`         | Validate and apply avatar, voice, and ChatBox decisions                       |
| `vrchat_ai_avatar_chatbox`                | Send through the autonomous ChatBox guard when explicitly enabled             |
| `vrchat_ai_avatar_voicevox_request`       | Inspect VOICEVOX `audio_query` and `synthesis` request metadata               |

Start VOICEVOX Engine locally before using voice synthesis. The default
VOICEVOX endpoint is `http://127.0.0.1:50021`. If generated speech should enter
VRChat as microphone audio, configure a virtual audio cable manually in the
operating system and select that device in VRChat. OpenClaw does not change
VRChat audio devices.

In Public instances, keep `chatBox.enabled=false` and `movement.enabled=false`
unless the user has explicitly opted in. ChatBox output is capped to 144
characters and 9 lines and is rate-limited.

| `vrchat_get_online_friends` | List online friends and their locations |

### OSC & Input (PRO)

| Tool              | Description                               |
| ----------------- | ----------------------------------------- |
| `vrchat_send_osc` | Send raw OSC message                      |

### Camera Control (DIRECTOR)

| Tool                        | Description                                            |
| --------------------------- | ------------------------------------------------------ |
| `vrchat_camera_set`         | Set camera parameters (Zoom, Aperture, Focal Distance) |
| `vrchat_camera_greenscreen` | Set GreenScreen HSL for chroma key                     |
| `vrchat_camera_lookatme`    | Set LookAtMe composition                               |
| `vrchat_camera_capture`     | Trigger camera capture                                 |

### OSC Listener

| Tool                     | Description                             |
| ------------------------ | --------------------------------------- |
| `vrchat_start_listener`  | Start OSC listener on port 9001         |
| `vrchat_stop_listener`   | Stop OSC listener                       |
| `vrchat_listener_status` | Get listener status and recent messages |

### Guardian Pulse

Autonomous heartbeat that periodically sends chatbox messages and avatar emotion changes to maintain presence in VRChat.

| Tool                           | Description                                     |
| ------------------------------ | ----------------------------------------------- |
| `vrchat_guardian_pulse_start`  | Start autonomous periodic messages and emotions |
| `vrchat_guardian_pulse_stop`   | Stop the Guardian Pulse                         |
| `vrchat_guardian_pulse_status` | Get current pulse status                        |

Guardian Pulse auto-starts when the plugin loads (5-minute interval).

### Audit & Diagnostics

| Tool                       | Description                        |
| -------------------------- | ---------------------------------- |
| `vrchat_audit_logs`        | View operation logs                |
| `vrchat_reset_rate_limits` | Reset rate limiters (testing only) |

## Rate Limits

| Action           | Limit                    |
| ---------------- | ------------------------ |
| Chatbox messages | 5 messages per 5 seconds |
| Input commands   | 20 commands per second   |
| Camera commands  | 10 commands per second   |

## Configuration

```json
"plugins": {
  "entries": {
    "vrchat-relay": {
      "enabled": true,
      "llm": {
        "allowModelOverride": true,
        "allowedModels": ["openai/gpt-5.5"]
      },
      "config": {
        "osc": {
          "outgoingPort": 9000,
          "incomingPort": 9001,
          "host": "127.0.0.1"
        },
        "autonomousVrchatAi": {
          "enabled": false
        },
        "inputHub": {
          "textBox": { "enabled": true },
          "speechToText": { "enabled": false },
          "visionObservation": { "enabled": true },
          "streamComment": { "enabled": true }
        },
        "orchestrator": {
          "model": "gpt-5.5",
          "reasoning": { "effort": "low" }
        },
        "voicevox": {
          "enabled": true,
          "baseUrl": "http://127.0.0.1:50021",
          "speaker": 1
        },
        "audioOutput": {
          "mode": "speaker"
        },
        "vrchatOsc": {
          "enabled": true,
          "host": "127.0.0.1",
          "sendPort": 9000,
          "receivePort": 9001,
          "allowRemoteOsc": false,
          "autoDiscoverAvatarConfig": true
        },
        "behavior": {
          "mode": "subtle",
          "idleMinIntervalMs": 30000,
          "idleMaxIntervalMs": 90000,
          "actionCooldownMs": 15000,
          "emotionCooldownMs": 3000,
          "maxCommandsPerSecond": 6
        },
        "movement": {
          "enabled": false,
          "allowInPublicInstances": false
        },
        "chatBox": {
          "enabled": false,
          "maxChars": 144,
          "maxLines": 9
        },
        "speechToText": {
          "enabled": false,
          "suppressDuringTts": true
        },
        "safety": {
          "requireOscJsonParameterPresence": true,
          "disableChatBoxByDefault": true,
          "emergencyStopHotkey": "Ctrl+Alt+O"
        },
        "mirror": { "syncAiResponseToChatbox": false }
      }
    }
  }
}
```

With `disableChatBoxByDefault=true`, assistant replies are not mirrored into
the VRChat ChatBox unless you explicitly set
`mirror.syncAiResponseToChatbox=true`.

## Typical Workflow

```
1. Log in with the official VRChat client.
2. Enable OSC from the VRChat Action Menu.
3. Wear the published avatar once so VRChat generates its OSC JSON.
4. Start VOICEVOX Engine when voice output is needed.
5. Run hypura_harness_vrc_status and hypura_harness_vrc_parameters.
6. Generate, review, and approve an action profile before sending VRChat actions.
7. Use companion3d events when no approved VRChat action is available.
```
